# File Optimizer MVP

Локальный браузерный MVP для оптимизации файлов разных типов без загрузки пользовательских файлов на сервер.

## Поддерживаемые типы

- изображения: JPG, JPEG, PNG, WebP, BMP;
- видео: MP4, MOV, MKV, WebM, AVI, M4V, MPEG через FFmpeg WebAssembly;
- аудио: MP3, WAV, M4A, AAC, OGG, FLAC, OPUS, WMA через FFmpeg WebAssembly;
- Office: DOCX, XLSX, PPTX и макро-варианты;
- PDF: структурное пересохранение;
- ZIP: повторная lossless-компрессия;
- JSON: минификация;
- прочие форматы: упаковка в ZIP без изменения содержимого.

## Режимы

- Бережный
- Баланс
- Максимум

## Безопасность

Файлы обрабатываются через File API браузера в памяти устройства. Исходники не отправляются в backend. Интернет используется только для загрузки JS/WASM-библиотек с CDN.

## Ограничения MVP

- для больших видео и аудио требуется значительный объём RAM;
- файлы медиа больше 650 МБ блокируются браузерной версией;
- PDF без перекодирования встроенных изображений может уменьшаться незначительно;
- неизвестные форматы не модифицируются и упаковываются в ZIP без потерь;
- для production рекомендуется хранить зависимости локально, добавить CSP/SRI и отдельный локальный worker для тяжёлых файлов.
